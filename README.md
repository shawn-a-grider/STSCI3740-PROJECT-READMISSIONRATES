# STSCI3740-PROJECT-READMISSIONRATES
"US Hospital data. The goal is to predict the patient readmission. A detailed description of the data is in the UCI website. https://archive.ics.uci.edu/dataset/296/diabetes+130-us+hospitals+for+years+1999-2008"

Install the dependencies with 

```bash
Rscript install_packages.R
```

For loading the cleaned data into an R script for analyzing data, use 

```
library(here)
source(here("data","get_data.R"))
```
